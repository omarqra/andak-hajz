# عندك حجز

**منصّة حجز الملاعب وتنظيم الماتشات في سوريا.**

## تنزيل التطبيق

[**⬇️ نزّل آخر نسخة**](https://github.com/omarqra/andak-hajz/releases/latest)

ملف واحد بيشتغل على كل أجهزة الأندرويد — قديمة وجديدة.

### كيف تنصّبو

1. نزّل الملف من الرابط فوق.
2. افتحو من قائمة التنزيلات بالتلفون.
3. أول مرّة رح يسألك الأندرويد يسمحلك تنصّب من مصدر خارج المتجر — اضغط **«السماح»** أو **«إعدادات»** ثم فعّل الخيار، وارجع كمّل.
4. اضغط **تنصيب**.

إذا كان التطبيق منصّب عندك من قبل، هالملف بيحدّثو وبيضلّ حسابك فاتح — ما بتحتاج تحذف القديم.

### شو بتحتاج

- أندرويد ٧ أو أحدث
- اتصال إنترنت

---

## عن المشروع

تطبيق أندرويد للاعبين وأصحاب الملاعب، مع لوحة تحكّم للإدارة.

- **للاعب:** يدوّر على ملعب قريب، يحجز فترة، يعمل ماتش ويجمّع سكواد، وينظّم بطولة أو يتابعها.
- **لصاحب الملعب:** يدير ملاعبو وأوقات دوامو وأسعارو، ويقبل أو يرفض الحجوزات.

هالمستودع للتنزيل بس. الكود مو منشور هون.
